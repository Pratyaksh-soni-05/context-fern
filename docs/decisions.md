# Decisions log

One line per non-obvious decision. Newest first. Format: `YYYY-MM-DD · decision · reason · owner`.

- 2026-10-24 · splice.py's "shared pool" is every scrubbed session meeting `--min-exchanges` (default 6), built once and reused by reference across every variant and every one of `--streams` draws · comparing variants meaningfully requires them to draw from the same universe; a seed-driven further subsample wasn't specified and would need an arbitrary size, so the pool is simply "everything eligible" · Pratyaksh
- 2026-10-24 · After shuffling, adjacent segments from the same branch are merged into one continuous segment (`_merge_adjacent_same_branch`) before truth is assigned · a pure shuffle can by chance place two of a branch's own segments back to back, which would otherwise mint a "return" with zero intervening turns — not a real topic return, and not something a router needs any skill to detect; found by a test that started failing only after streams gained a per-stream seed suffix and happened to expose the case · Pratyaksh
- 2026-10-24 · Stray insertion (`_insert_strays`) picks distinct "insert before original index i" positions for i in [1, len-1] · this single constraint is sufficient to guarantee all three rules at once (never first, never last, never two adjacent), since any two distinct insertion points always have a real turn between them · Pratyaksh
- 2026-10-24 · The manifest hashes session ids (sha256, first 16 hex chars) rather than listing them raw, and records the stray file's own sha256 · session ids aren't secret, but the manifest may get shared or diffed outside the repo, so it defaults to not being a lookup table back to specific sessions; the stray-file hash lets a result be traced to the exact committed list that produced it · Pratyaksh
- 2026-10-24 · Label files are an append-only JSONL journal keyed by exchange index; `load_labels` resolves duplicates by taking the last line for each index · lets "back" (re-labelling an earlier exchange) just append rather than needing in-place file rewriting, at the cost of the file growing slightly on every correction · Pratyaksh
- 2026-10-24 · Renamed ContextTree/ctree to Context Fern/fern everywhere (brand.ts, CLAUDE.md, user-facing docs); adopted spec §4 vocabulary (stem, frond, leaflet, stray, root, graft) in packages/core/src/types.ts and in user-facing text · the name and visual design are now locked, so the "placeholder" framing from the Phase 0 scaffold no longer applies; `fern` the CLI name may still change per docs/spec.md's own header, which is why brand.ts stays the single source of truth · Pratyaksh
- 2026-10-24 · RouterAction gains a fifth value, `stray` (an off-topic exchange, answered and excluded from every frond); added `DecisionAction = RouterAction | "merge"` so a plain merge-to-stem and a two-frond combine are both journalable without a new action, and `Decision` gained `with?` (the second frond for a combine), `stage` (0 or 2) and `rootsUsed?` to match spec §5's router output shape · undo stays the `undone` flag plus the inverse, not a new action · Pratyaksh
- 2026-10-24 · `Leaflet` (was `Turn`) models one exchange, not one message record: `frondId: string | null` (null = stray), `strayFrom: string | null` (the frond or stem a stray interrupted, for the UI to draw it shooting off that point), `filesTouched` is now `{ path, source }[]` instead of bare strings · matches how bench/transcript.py already defines an exchange, and the UI needs the interrupted frond to draw a stray, not just the fact that it is one · Pratyaksh
- 2026-10-24 · `Root` is scoped to a project (`projectPath`), not a session · roots are memories from earlier sessions and can feed any session opened in the same project; which leaflet actually used a root is recorded on that leaflet's `Decision.rootsUsed`, not on the Root · Pratyaksh

- 2026-10-23 · ReplayBench's routing unit is the exchange (one human prompt + everything up to the next human prompt), not the raw JSONL record; a human prompt is a `user` record with a text block and no `tool_result` block — verified against real transcripts, 237/8799 non-sidechain `user` records classify as human prompts with zero ambiguous/mixed cases · matches how a person actually experiences turns; the 1:8562 ratio of prompts to tool-result records would otherwise swamp any per-record signal · Pratyaksh

- 2026-10-23 · Absolute-path scrubbing is two-tier: known path-bearing fields (`cwd`, `file_path`, ...) are relativized/opaqued as a whole value; free text gets a best-effort no-spaces regex, backed by the denylist as a last resort · a regex can't safely allow spaces inside a free-text path match without swallowing surrounding prose, but our own home directory ("User Name") has a space — the structured-field path handles that exactly; the denylist mops up what the free-text regex under-matches · Pratyaksh
- 2026-10-23 · Windows- and POSIX-style absolute-path regexes run as one combined pattern/pass, not two sequential ones · two sequential passes let the POSIX branch re-match the `/repo/...` tail of the `<PATH:...>` placeholder the Windows pass had just produced, double-wrapping it into `<PATH:<PATH>>` — caught by a test, fixed by combining into one non-overlapping pass · Pratyaksh
- 2026-10-23 · Email placeholders are indexed (`<EMAIL:1>`, `<EMAIL:2>`, ...) rather than a flat `<EMAIL>`, scoped per `sessionId` · a flat tag makes "same email maps to the same placeholder" trivially true for the wrong reason; indexing preserves same-person-vs-different-person signal without the real address · Pratyaksh

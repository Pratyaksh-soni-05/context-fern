- 2026-10-24 · splice.py's "shared pool" is every scrubbed session meeting `--min-exchanges` (default 6), built once and reused by reference across every variant and every one of `--streams` draws · comparing variants meaningfully requires them to draw from the same universe; a seed-driven further subsample wasn't specified and would need an arbitrary size, so the pool is simply "everything eligible" · Pratyaksh
- 2026-10-24 · After shuffling, adjacent segments from the same branch are merged into one continuous segment (`_merge_adjacent_same_branch`) before truth is assigned · a pure shuffle can by chance place two of a branch's own segments back to back, which would otherwise mint a "return" with zero intervening turns — not a real topic return, and not something a router needs any skill to detect; found by a test that started failing only after streams gained a per-stream seed suffix and happened to expose the case · Pratyaksh
- 2026-10-24 · Stray insertion (`_insert_strays`) picks distinct "insert before original index i" positions for i in [1, len-1] · this single constraint is sufficient to guarantee all three rules at once (never first, never last, never two adjacent), since any two distinct insertion points always have a real turn between them · Pratyaksh

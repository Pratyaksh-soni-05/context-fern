# Decisions log

One line per non-obvious decision. Newest first. Format: `YYYY-MM-DD · decision · reason · owner`.

- 2026-10-23 · ReplayBench's routing unit is the exchange (one human prompt + everything up to the next human prompt), not the raw JSONL record; a human prompt is a `user` record with a text block and no `tool_result` block — verified against real transcripts, 237/8799 non-sidechain `user` records classify as human prompts with zero ambiguous/mixed cases · matches how a person actually experiences turns; the 1:8562 ratio of prompts to tool-result records would otherwise swamp any per-record signal · Pratyaksh
- 2026-10-23 · Sidechain detection keyed on `isSidechain: true` (always paired with a non-empty `agentId` in real data; a dedicated `agent-*.jsonl` file is 100% sidechain) · excluding these from exchanges but still char-counting them separately keeps sub-agent noise out of the branch definition without hiding how much work happened there · Pratyaksh
- 2026-10-23 · Absolute-path scrubbing is two-tier: known path-bearing fields (`cwd`, `file_path`, ...) are relativized/opaqued as a whole value; free text gets a best-effort no-spaces regex, backed by the denylist as a last resort · a regex can't safely allow spaces inside a free-text path match without swallowing surrounding prose, but our own home directory ("User Name") has a space — the structured-field path handles that exactly; the denylist mops up what the free-text regex under-matches · Pratyaksh
- 2026-10-23 · Windows- and POSIX-style absolute-path regexes run as one combined pattern/pass, not two sequential ones · two sequential passes let the POSIX branch re-match the `/repo/...` tail of the `<PATH:...>` placeholder the Windows pass had just produced, double-wrapping it into `<PATH:<PATH>>` — caught by a test, fixed by combining into one non-overlapping pass · Pratyaksh
- 2026-10-23 · Email placeholders are indexed (`<EMAIL:1>`, `<EMAIL:2>`, ...) rather than a flat `<EMAIL>`, scoped per `sessionId` · a flat tag makes "same email maps to the same placeholder" trivially true for the wrong reason; indexing preserves same-person-vs-different-person signal without the real address · Pratyaksh
- 2026-10-23 · `combine` splice rows add an optional `combine_with: [branch_id]` field alongside the fixed `{stream_id, turn_index, branch_id, action_truth, variant, turn}` shape · the fixed shape has nowhere to put the second branch a combine turn needs; adding a field only on combine rows beats overloading `branch_id` · Pratyaksh

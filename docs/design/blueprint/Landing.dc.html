Anatomy

Read a session like a plant.

Long agent sessions wander. Each wander gets its own frond, so the model never carries a tangent into the task.

stemThe task itself, shared by every frond.
frondsOne per topic, each with a markdown brief you can edit.
leafletsEvery turn, on the frond it belongs to, with the reason why.
straysOff-topic questions, answered, then kept off every frond.
rootsMemories from earlier sessions, drawn where they feed a frond.

One session, three ways to look at it.

FernA

The whole session as one connected graph. Scrub through time; click any leaflet to see why it went there.

ListB

Every turn in order with its frond, the routing decision, its confidence and the context it carried.

CategoriesC

Grouped by frond, stray and root, with a map of when you switched topics.

Questions

Do I need an account?+

No. There is no account, sign-up or server. Context Fern is a binary on your machine.

Is it really free?+

Yes. Apache-2.0, and the license will not change. Nothing is held back for a paid tier.

Does my code leave my machine?+

No. The fern lives in .fern/ inside your project. Observe and suggest modes work offline. Optional router calls use your own key and show in the journal.

What if a turn lands on the wrong frond?+

Run /fern undo. In the default suggest mode, new fronds are proposed and you confirm them.

Does it replace memory tools?+

No. Memory tools remember across sessions; they become roots. Context Fern keeps this session clean.
